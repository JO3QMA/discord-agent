# ターンキューは完走後 FIFO（中断結合しない）

会話が単一飛行のあいだに届いた後続発話は、実行中ターンを `cancel` して結合するのではなく、ターンキューに載せ、現ターン終了後に先頭から独立ターンとして処理する。各発話の意図・添付・定着レビュー単位を保ち、待ちは ∞、破棄（`/stop`・`/new`・セッション消滅）は件数告知と ❌ で見えるようにする。

## Considered Options

- **中断して結合（旧）**: 後続到着で現ターンを cancel し、キュー全文を続くターンに結合する。速いが、途中結果が捨てられ、発話境界が溶ける。
- **完走後 FIFO（採用）**: 現ターンは完走し、待ちは一つずつ独立ターン。遅延は増えるが順序と単位が予測できる。
